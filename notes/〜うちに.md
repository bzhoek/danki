Terwijl .. nog, voordat .., zolang .. (situatie)

```
[situatie]内(うち)に[actie]
```
* ww-dict + うちに  
  alleen toestand ww: いる, ある, 出来る, 分かる  
  日本にいるうちに、富士山に登りたいです
* ww-te + いる + うちに  
  doorgaand 赤ちゃんが寝ているうちに、掃除をしよう
* ww-nai + うちに  
  voordat 忘れないうちにメモを取ります
* bn-i + うちに  
  zolang 温かいうちに食べてください
* bn-na + な + ために  
  zolang 元気なうちに
* zn + の + ために

De ない vorm komt vaak voor. De ている voor onbewuste verandering tijdens.  
Versus 〜間に voor objectief afgebakend tijdsblok
